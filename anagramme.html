Comment jouer

  • Les lettres d'un mot tournent dans le tourbillon, dans le désordre.
  • Touche une lettre : elle file se poser dans la prochaine case.
  • Touche une lettre posée pour la renvoyer dans le tourbillon.
  • L'ampoule pose une bonne lettre, mais ta série repart de zéro.
  • Le bouton « Mélanger » fait tourbillonner les lettres.
  • Trouve le mot : il s'illumine, et ta série grimpe !
